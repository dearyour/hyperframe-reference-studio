# Reference matching

Write a compact shot specification before choosing a template:

| Observe | Record |
|---|---|
| Scope | Source range, target graphic bounds, exclusions such as presenter or application chrome |
| Geometry | Main object anchors, size ratios, gaps, stacking and overlap |
| Type | Font approximation, weight, line breaks, density and contrast |
| Material | Background, fills, edges, shadows and depth |
| Motion | Initial, intermediate and final poses; activation order; acceleration; hold |
| Content | Exact provided copy, sourced replacements and illustrative data |
| Evidence | Source/output frames at corresponding phases |

Start with broad sampling, then extract adjacent frames around meaningful changes. Distinguish measured positions from estimated timing and easing. A screen recording's nominal frame rate may differ from the animation being recorded.

Compare the same subject at the same phase. A title appearing in place of a dashboard is a composition mismatch even when its colors match. If a three-card layout is selected, preserve its proportions and subject hierarchy before adding decorative details. Do not animate every object with an identical fade-up when the reference shows counting, line drawing and sequential activation.

Retain a short proof and its source before expanding. If content length requires a different layout, describe the change; do not call it an exact reconstruction. Inspect decoded final frames in addition to browser previews.

For references supplied by other creators, keep permission and attribution separate from technical access. A downloaded video, screen recording or reconstructed logo is not evidence of redistribution rights. Use original or suitably licensed demonstration assets for a public package.
